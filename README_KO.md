# QA-SSEC 공개 재현 자료 v1.1.0 후보

기존 v1.0.0 분석 결과에 과거 D4의 원래 입력·분할표·예측 원본과 검산을 연결한 자료입니다.
연구 수치와 원래 학습 코드는 변경하지 않았습니다.

## 저장 결과 검산

Python 3.8 이상의 표준 라이브러리만 사용합니다.

```text
python -I -B VERIFY_PUBLIC.py
```

기존 증명서 32개, 원래 재생성 결과 14개, 회수한 D4 입력·예측 검산 출력 2개를 확인합니다.
D4는 B01/B02 예측 40개 파일·600행을 정답과 fold에 연결하고, 160개 test 집계값과
12개 대응 비교, TABLE X를 원본 예측에서 다시 계산합니다.

검산 명령은 학습·추론·원본 질의·토큰화·패킹·설치·다운로드를 실행하지 않습니다.
결과는 `reproduced/`에 분리하며, 다시 실행하면 무결성을 확인한 완료 결과를 재사용합니다.

## 원래 모델 실행의 자료

`historical/FROZEN_INPUTS.zip`에는 공개 RCAEval 기반의 adapter 75사례·8,299 metrics,
375행 분할표, B01–B04 표현별 75개 입력, 고정 tokenizer와 설정, 정답·예측 파일이 있습니다.
고정 모델 가중치는 별도 공식 출처에서 확보합니다. 원래 학습기의 명령과 의존성은
`historical/README.md`에 분리했으며, 기본 검산이 학습기를 호출하지 않습니다.
HMAC 생성 비밀키, 회사 문서와 대응 절차, 회수용 내부 스크립트는 포함하지 않았습니다.

## 배포 상태

현재 파일은 로컬에서 구성한 다음 공개 버전 후보입니다. 기존 v1.0.0이나 GitHub를
자동 변경하지 않습니다. 논문에서 새 자료가 공개됐다고 기술하는 것은 실제 게시 후에 합니다.
원본 처리·패킹·질의의 전체 연결 범위와 실행 확인 수준은 ARTIFACT_SCOPE.md에 있습니다.
