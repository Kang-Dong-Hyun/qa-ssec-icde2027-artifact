# QA-SSEC 텔레메트리 뷰 평가 — 저장 결과 검산 자료

이 저장소는 공개 RCAEval 기반의 평가 결과, 분석 코드, 32개 방향별 증명서와 검증 실행기를 제공합니다.

## 실행

Python 3.8 이상에서 다음 명령을 실행합니다. 표준 라이브러리만 사용합니다.

```powershell
python -I -B .\VERIFY_PUBLIC.py
```

입력 파일 해시 확인, 증명서 32개 검사, 저장 결과 분석, 기존 JSON/CSV 14개의 바이트 일치를 확인합니다. 출력은 `reproduced` 하위에 생성하며 입력은 수정하지 않습니다. 완료 후 재실행하면 기존 검산 출력을 확인하여 재사용합니다.

네트워크 접속, Conda/pip 설치, 모델 학습·추론, 원본 질의 평가, 토큰화·패킹은 실행하지 않습니다.

## 수록 범위

- 공개 benchmark에서 산출된 개발·반복 전이·동일 수량 평가 CSV/JSON
- witness 보존, 요구 수준, AND/OR, 공분산, COUNT/FRACTION, COUNT 하한 분석
- 유한 패널 비교 증명서와 별도 검사 코드
- 공개 RCAEval adapter 참고 코드, 고정 revision과 원본 파일 해시

회사 장비 매뉴얼, 시스템 구성·운영 문서, 장애 대응 절차, 내부 EMS 로그, 인증정보, 과거 연구 저장소의 Git 이력은 공개 대상으로 포함하지 않았습니다. 공개 benchmark의 집단 이름과 해시형 사례 키는 재현 연결을 위해 유지합니다.

## 재현 범위

이 저장소의 검산 성공은 **저장 결과에서의 분석 재현**입니다. 원본 Parquet부터 모든 선택·질의 결과를 다시 만드는 통합 경로 및 과거 모델 학습 실험은 포함되지 않습니다. 상세 범위는 `ARTIFACT_SCOPE.md`를 참조하십시오. 이 범위를 논문 전체의 원본 재실행 완료로 바꾸어 표기하지 않습니다.

## Git에 넣는 파일

`FILE_MANIFEST_SHA256.csv`에 정한 파일과 그 manifest만 공개 대상으로 삼습니다. `.gitignore`는 이 허용 목록만 추적할 수 있도록 구성했고, `.gitattributes`는 파일 해시를 보존하도록 줄바꿈 자동 변환을 차단합니다. 새 데이터·노트·스크립트를 추가하려면 별도 내용 검토와 목록 갱신이 필요합니다.

이번 패키징에서 코드에 MIT/Apache 등 새로운 이용허락을 임의로 부여하지 않았습니다. 공개 데이터의 고유 라이선스는 `THIRD_PARTY_NOTICES.md`에 구분되어 있습니다.
